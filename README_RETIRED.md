# RETIRED — dynajs lives on inside `ladyna`

**2026-08-22.** This package (`dynajs`, the "Lite TNA + Pattern Discovery"
fork of tnaj) is retired as part of the one-engine consolidation. Do not add
features or consumers here.

## Where everything went

The engine formerly named `tnaj` (sibling repo `../tna-js`) was renamed
**`ladyna`** and absorbed the four dynajs-only exports; everything else on
dynajs's surface already existed there under identical names (same fork
lineage, verified numerically):

| dynajs export | ladyna equivalent |
|---|---|
| `networkDensity`, `degreeDistribution` | same names — `src/analysis/lite.ts` (verbatim port) |
| `communities` | **`detectCommunities`** — `src/analysis/lite.ts` (verbatim port; ladyna's own `communities` is the R-tna multi-method verb with a different shape) |
| `stateFrequencies` | **`stateCounts`** — `src/analysis/lite.ts` (verbatim port; ladyna's own `stateFrequencies` is the Nestimate-parity tidy-row verb) |
| `statePresence` | same name — `src/analysis/lite.ts` |
| `layout` | same name — `src/core/layouts.ts` (wrapper over ladyna's 22-layout engine; same `[0,1]`-normalized contract, coordinates not bit-identical) |
| everything else (`tna`, `buildModel`, `centralities`, `prune`, `discoverPatterns`, `buildDFG…`, `summary`, `Matrix`, …) | same names, same shapes |

Parity tests: `tna-js/tests/lite.test.ts` (ground truth generated by running
this package's own dist build).

## Former consumers (all repointed 2026-08-22, all suites green)

LAILA-v3/client, Sonnet, disnet, moodle-tna, chatoyon-plus (+ -groups,
-oyon-v3-beta incl. their public dashboards and CI/deploy scripts),
rohySimulator (+ -2.9 incl. OyonR standalone vendor), tna-react.

Import with `from 'ladyna'` (`"ladyna": "file:../tna-js"`), renaming only
`communities` → `detectCommunities` and `stateFrequencies` → `stateCounts`.
